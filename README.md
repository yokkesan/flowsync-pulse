# FlowSync Pulse

バーチャルオフィス兼作業可視化サービスです。

2Dバーチャルオフィス上でメンバーの在席状況を確認し、VS Code拡張機能から取得したGitブランチ情報を連携することで、誰がどの作業に取り組んでいるかを可視化します。

## 主な機能

* 2Dバーチャルオフィス
* アバター位置のリアルタイム同期
* メンバーの在席・作業状況表示
* 同一エリア内での音声通話
* VS Code拡張機能との連携
* Gitブランチ・タスク情報の可視化
* ブランチ単位の作業履歴保存
